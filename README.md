# Student Result Management System

This is a simple C project for the **CSE103 (Structured Programming)** course at East West University.

## Description
This program reads student records from a text file (`student_input.txt`), calculates their CGPA based on specific course credits, and saves a formatted grade sheet into an output file (`output.txt`).

## Course Credits
* **CSE103:** 4.5 Credits
* **MAT101:** 3.0 Credits
* **ENG7101:** 3.0 Credits

## How to Run
1. Make sure `main.c` and `student_input.txt` are in the same folder.
